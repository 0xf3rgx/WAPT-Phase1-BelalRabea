## About

This repository contains my Phase 1 submission for the WAPT internship at IqraSec Academy. It covers four core areas of web application security, learned and practiced through TryHackMe rooms and PortSwigger Web Security Academy labs.

Each task includes a written report (Objective, Concept, Practical Work, Tools Used, Evidence, Result, Key Learnings, and — for vulnerabilities — Impact and Remediation) along with supporting screenshots.

## Topics Covered

| Area | Rooms / Labs |
|---|---|
| **Web Fundamentals** | HTTP/HTTPS, requests & responses, methods, headers, status codes |
| **Recon & Enumeration** | Passive recon (WHOIS, DNS), active recon (ping, traceroute, netcat), content discovery |
| **Burp Suite** | Repeater, request modification, Union-based SQL injection |
| **Common Web Vulnerabilities** | IDOR, SQL Injection, Reflected XSS, Authentication (username enumeration & brute-force), Path Traversal |
